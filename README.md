# Агент поддержки интернет-магазина — Чекпоинт 1

## Стоимость диалога

Диалог: пользователь просит отменить заказ 54010. Агент делает 2 вызова инструментов: `get_order` и `cancel_order`.

Цены DeepSeek Chat (на октябрь 2026):
- Входные токены: $0.27 за 1 млн
- Выходные токены: $1.10 за 1 млн

Расход по типу диалога:

| Тип | Вход (токены) | Выход (токены) | Стоимость |
|-----|--------------|----------------|-----------|
| Без инструментов (1 итерация) | ~600 | ~150 | $0.000327 |
| С 1 инструментом (2 итерации) | ~900 | ~200 | $0.000463 |
| С 2 инструментами (3 итерации) | ~1200 | ~280 | $0.000632 |

Расчёт для диалога с 2 инструментами (сценарий отмены заказа 54010):
```
входные:  1200 / 1_000_000 * 0.27 = $0.000324
выходные:  280 / 1_000_000 * 1.10 = $0.000308
итого:  $0.000632
```

Средняя цена диалога по 10 сценариям: **~$0.000474**

## Reasoning effort

Выбран effort: **low**

Обоснование: задача агента поддержки простая и хорошо структурированная — найти заказ по номеру и выполнить одно действие. Здесь не нужны сложные многошаговые рассуждения. `low` даёт быстрый ответ и минимальный расход токенов. `medium` или `high` оправданы только если агент решает неоднозначные ситуации — например конфликтующие правила возврата — чего в базовом сценарии нет.
