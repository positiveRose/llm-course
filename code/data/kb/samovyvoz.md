# Самовывоз

Самовывоз из пунктов выдачи бесплатный. Заказ хранится в пункте 5 дней, срок можно продлить один раз ещё на 5 дней в личном кабинете. Для получения нужен номер заказа и код из SMS. Проверить товар и вскрыть упаковку можно на месте в присутствии сотрудника. Если товар не подошёл, отказаться от него можно сразу в пункте выдачи, деньги вернутся по обычной процедуре.
