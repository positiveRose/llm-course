# Смарт-часы: подключение и датчики

Часы подключаются через фирменное приложение, а не через настройки Bluetooth телефона. Если часы не видны, удалите их из списка устройств Bluetooth и повторите сопряжение из приложения. Пульсометр требует плотного прилегания ремешка на два пальца выше косточки запястья. Автономность 7 дней указана при отключённом постоянном измерении пульса и яркости экрана до 50 процентов.
