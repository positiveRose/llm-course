# Обмен товара

Обмен на другой размер, цвет или модель оформляется как возврат и новый заказ. Если новый товар дороже, разница оплачивается при оформлении, если дешевле, разница возвращается вместе с возвратом за первый товар. Обмен доступен в те же 14 дней, что и возврат. Для ускорения можно оформить новый заказ сразу, не дожидаясь проверки возвращённого товара.
