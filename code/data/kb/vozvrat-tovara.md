# Возврат товара

Вернуть товар надлежащего качества можно в течение 14 дней с момента получения, не считая дня покупки. Товар должен быть без следов использования, с сохранённой упаковкой, пломбами и комплектацией. Для возврата оформите заявку в личном кабинете в разделе «Мои заказы» или напишите в поддержку с номером заказа. Курьер заберёт товар бесплатно при заказе от 5000 рублей, иначе вернуть можно в пункт выдачи. Не подлежат возврату товары с нарушенной индивидуальной упаковкой: наушники-вкладыши, электрические зубные щётки, бритвы.
