# Часы работы поддержки

Поддержка отвечает ежедневно с 9:00 до 21:00 по московскому времени, без выходных. Обращения, полученные ночью, попадают в очередь и разбираются с 9:00 в порядке поступления. Среднее время ответа в чате 5 минут, по почте до 4 часов в рабочее время. В праздничные дни график может сокращаться, об этом сообщается на сайте заранее.
