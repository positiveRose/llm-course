# Способы оплаты

Принимаем банковские карты Visa, Mastercard и Мир, оплату через СБП, электронные кошельки и наличные курьеру или в пункте выдачи. Юридические лица могут оплатить по счёту. Оплата картой на сайте проходит через защищённый шлюз, данные карты в магазине не хранятся. При оплате наличными курьеру сдача есть всегда, сумма заказа при этом не должна превышать 100 000 рублей.
