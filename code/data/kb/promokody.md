# Промокоды и скидки

Промокод вводится в корзине перед оплатой, применяется только один промокод на заказ. Скидка по промокоду не суммируется с акционными ценами и оплатой бонусами, действует более выгодное предложение. Если промокод не применился, проверьте срок действия и минимальную сумму заказа в условиях акции. Применить промокод к уже оплаченному заказу нельзя, можно отменить заказ и оформить заново, пока он не передан в доставку.
