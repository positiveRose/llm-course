# Личный кабинет

В личном кабинете хранятся заказы, адреса доставки, бонусный счёт и заявки на возврат. Вход по номеру телефона и коду из SMS, пароль не нужен. Если SMS не приходит, проверьте, не заблокированы ли короткие номера у оператора, и запросите код повторно через 60 секунд. Изменить номер телефона можно в настройках профиля, подтвердив старый и новый номера.
