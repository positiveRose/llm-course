# Как связаться с поддержкой

Написать в поддержку можно в чате на сайте и в приложении, по почте support@example-shop.ru и по телефону 8 800 000-00-00 (звонок бесплатный). При обращении укажите номер заказа, он ускоряет ответ. Претензии по качеству товара принимаются в письменном виде через форму в личном кабинете, к ним можно приложить фото и видео до 50 МБ.
