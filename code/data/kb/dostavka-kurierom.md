# Курьерская доставка по городу

Курьерская доставка по городу занимает 1–2 дня. Интервалы доставки: 9:00–14:00, 14:00–18:00, 18:00–22:00. При заказе до 15:00 доставка возможна на следующий день. Стоимость 300 рублей, при сумме заказа от 5000 рублей бесплатно. Курьер звонит за 30–60 минут до приезда. Крупногабаритная техника (холодильники, стиральные машины) доставляется отдельной службой в течение 2–4 дней, подъём на этаж оплачивается отдельно.
