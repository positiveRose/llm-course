# Персональные данные и удаление аккаунта

Мы храним номер телефона, адреса доставки и историю заказов для выполнения заказов и гарантийных обязательств. Удалить аккаунт можно через поддержку, заявка выполняется в течение 30 дней. История заказов после удаления недоступна, гарантийные обращения по ним принимаются только по чеку. Рассылки отключаются в настройках профиля в один клик, служебные уведомления о заказах отключить нельзя.
